受注残・進捗管理表 説明書

営業所ごとの受注残、見込み、実績、目標進捗を管理するための操作説明書です。各営業所の所長・担当者へ配布して、そのまま印刷して使えます。

1. 初回の端末設定

URLを初めて開くと、最初に「端末設定」画面が表示されます。ここで営業所ごとの保存先を決めます。

最初に入力するもの

  1. 設定コード: 営業所を識別するコードです。
  2. アクセスコード: 同じ営業所の人だけで共有する5文字以上のコードです。

設定コードの入力例

営業所 設定コード例 任意の営業所コード例
田川営業所 田川 TSS110
行橋営業所 行橋 TSS250

重要

同じ営業所で同じデータを使う場合は、全員が同じ「設定コード」と同じ「アクセスコード」を入力してください。どちらかが違うと、別の営業所データとして扱われます。

端末設定の手順

  1. アプリのURLを開きます。
  2. 「設定コード」に営業所名または任意の営業所コードを入力します。
  3. 「アクセスコード」に、営業所内で共有する5文字以上のコードを入力します。
  4. 「設定を保存して開始」を押します。
  5. 次回からは同じ端末では自動的にその営業所の画面が開きます。

端末設定を変更したい場合は、画面右上の「設定変更」から再設定できます。

2. ショートカットの作成

アプリはURLを毎回入力しなくても、パソコンのデスクトップやiPadのホーム画面にショートカットを作って使えます。

ショートカット作成後の動き

初めてショートカットから開いた端末では、最初に「端末設定」画面が表示されます。設定コードとアクセスコードを入力すると、次回から同じ営業所の画面が開きます。

パソコンのデスクトップにショートカットを作る方法

  1. パソコンで、配布された公開URLをブラウザで開きます。
  2. ブラウザのアドレスバー左側にある鍵マーク、またはサイトアイコンを確認します。
  3. そのマークをデスクトップへドラッグします。
  4. デスクトップにできたショートカットを開き、端末設定を行います。

iPadのホーム画面にショートカットを作る方法

  1. iPadでSafariを開き、配布された公開URLを開きます。
  2. 画面上部または下部にある共有ボタンを押します。
  3. 「ホーム画面に追加」を選びます。
  4. 名前を「受注残・進捗管理表」など分かりやすい名称にして「追加」を押します。
  5. ホーム画面にできたアイコンを開き、端末設定を行います。

注意

同じ営業所で使う端末には、必ず同じ設定コードとアクセスコードを入力してください。ショートカットを作っただけでは営業所データは共有されません。初回の端末設定まで行ってください。

3. マスタ設定

最初は担当者や予算は入っていません。各営業所で必要な担当者を追加してください。

担当者の追加

  1. 「マスタ設定」タブを開きます。
  2. 「新所員名を入力」に担当者名を入力します。
  3. 「スタッフ追加」を押します。
  4. 追加された担当者に、必要な予算や目標を入力します。

入力する主な項目

項目 内容
住改予算 住宅改修の月間予算です。
住改件数 住宅改修の目標件数です。
特定福祉用具予算 特定福祉用具販売の月間予算です。
特定福祉用具件数 特定福祉用具販売の目標件数です。
レンタル目標 レンタル新規の目標件数です。
特価目標 特価ベッドの目標台数です。

4. 基本の使い方

画面上部のタブを切り替えて操作します。

タブ名 使う場面
登録 新規案件、追加案件、住宅改修、販売などを入力します。
受注残一覧 登録済み案件の確認、状態変更、次月繰越を行います。
営業所合計 営業所全体の実績、見込み、受注残合計を確認します。
目標進捗 担当者ごとの目標に対する達成状況を確認します。
推移グラフ 年度内の月別実績、依頼元の内訳、前年との比較を確認します。
マスタ設定 担当者名、予算、目標数値を登録します。必要に応じてデータ出力・読み込みも行えます。

5. 新規案件の登録

日々の案件は「登録」タブから入力します。正確な進捗管理のため、出来る限り案件が発生したタイミング、もしくは受注残の報告前に一括で入力することをおすすめします。

登録手順

  1. 「登録」タブを開きます。
  2. カテゴリを選びます。例: レンタル新規、既存追加、特価ベッド、住宅改修など。
  3. 担当者を選びます。
  4. 利用者様名、金額、状態、区分、事業所名を入力します。
  5. 必要に応じて「翌月繰越として登録」にチェックを入れます。
  6. 「案件を登録」を押します。

任意項目について

「一般販売」「紙おむつ」「消耗品」は任意項目です。通常は画面をすっきりさせるため非表示になっています。

  1. 必要な場合だけ「＋ 任意項目を入力する」を押します。
  2. 一般販売、紙おむつ、消耗品のボタンが、通常項目と同じ大きさで表示されます。
  3. 該当する任意項目を選び、利用者様名や金額を入力します。
  4. 入力した金額は、営業所合計や進捗ステータス詳細の「その他」として自動集計されます。

金額入力について

金額欄は手入力しやすいよう、数字入力欄の上下矢印を表示しない形にしています。金額は半角数字で入力してください。レンタル新規・既存追加では「月額」「半月」を選べます。

状態の考え方

  • レンタル系は「未確定」「確定済」で管理します。
  • 販売系は「未売上」「売上済」で管理します。
  • 実績に反映されるのは「確定済」または「売上済」になった案件です。
  • 見込みには登録されている案件が反映されます。

6. 受注残一覧の確認

「受注残一覧」では、登録した案件を月ごとに確認できます。

  1. 表示月を選びます。
  2. 営業所全体、または担当者ごとに絞り込みます。
  3. 依頼元やカテゴリで絞り込みます。
  4. 案件の状態を必要に応じて変更します。
  5. 翌月へ送る案件は「次月」にチェックを入れ、「次月へ移行」を押します。

修正・削除

一覧内の利用者様名、事業所名、金額、状態などは直接編集できます。不要な案件はゴミ箱ボタンで削除できます。

7. 営業所合計・印刷

「営業所合計」では、営業所全体の状況を確認できます。

  • レンタル新規の実績・見込み
  • 特価ベッドの実績・見込み
  • 住宅改修の件数・金額
  • 特定福祉用具販売の件数・金額
  • その他の金額（一般販売・紙おむつ・消耗品の合計）
  • 受注残合計

進捗ステータス詳細

担当者ごとの実績・見込みを一覧で確認できます。表示される項目は、受注残合計、レンタル新規、特価ベッド、住宅改修、特定福祉用具、その他です。

  • 「受注残合計」には、未確定のレンタル新規・既存追加・特価ベッドの合計金額が表示されます。
  • 「その他」には、一般販売・紙おむつ・消耗品の合計金額が表示されます。
  • 「その他」には目標設定がないため、目標欄は表示されません。
  • 実績は、状態が「確定済」または「売上済」になった案件のみ反映されます。
  • 見込みは、登録されている案件の合計として反映されます。

印刷方法

  1. 「営業所合計」タブを開きます。
  2. 必要に応じて依頼元フィルターを選びます。
  3. 「印刷」を押します。
  4. PDFまたは印刷画面が開いたら、内容を確認して印刷します。

印刷前の確認

印刷前に、表示月、営業所名、担当者別の進捗、実績・見込みの数字が正しいか確認してください。

8. 目標進捗・推移グラフ

目標進捗

「目標進捗」では、マスタ設定で入力した目標に対して、現在どこまで進んでいるかを確認できます。

  • レンタル新規目標
  • 特価ベッド目標
  • 住宅改修予算
  • 特定福祉用具販売予算

推移グラフ

「推移グラフ」では、4月から翌年3月までの年度実績を確認できます。営業所全体、または担当者ごとの推移を切り替えられます。

  • グラフは棒グラフで表示されます。
  • 今年度の実績は、依頼元の「包括」「居宅」などで色分けされます。
  • 前年の実績は、薄い色の棒で表示されます。
  • 今年度と前年を見比べることで、月ごとの伸びや落ち込みを確認できます。

9. データ入出力

マスタ設定の下部に、移行・バックアップ用の「データ入出力」があります。通常の運用では使用しませんが、端末変更や将来的な移行時に利用できます。

  1. 「マスタ設定」タブを開きます。
  2. 画面下部の「データ入出力」を確認します。
  3. バックアップを取る場合は「データ出力」を押します。
  4. 保存済みデータを読み込む場合は「データ読み込み」を押し、JSONファイルを選択します。

注意

データ読み込みを行うと、現在の営業所データを読み込みファイルの内容で上書きします。実行前に、必要であれば「データ出力」でバックアップを取ってください。

10. 運用ポイント

毎日行うこと

  • 新しい案件が出たら登録します。
  • 確定・売上になった案件は状態を更新します。
  • 翌月に回す案件は次月チェックを入れます。

月末に行うこと

  • 営業所合計で実績と見込みを確認します。
  • 担当者別の進捗を確認します。
  • 必要に応じて印刷して共有します。
  • 次月へ移行する案件を整理します。

11. よくある注意点

内容 確認すること
他の人と同じデータが見えない 設定コードとアクセスコードが同じか確認してください。
実績に反映されない 状態が「確定済」または「売上済」になっているか確認してください。
担当者が表示されない マスタ設定でスタッフ追加を行ってください。
任意項目が見つからない 登録画面の「＋ 任意項目を入力する」を押してください。
その他の数字が合わない 一般販売、紙おむつ、消耗品の金額と状態を確認してください。実績には「売上済」の案件だけが反映されます。
前年の棒グラフが薄く見える 前年実績は比較用のため、今年度より薄い色で表示しています。
データ読み込みが不安 先に「データ出力」でバックアップを保存してから読み込みを行ってください。
